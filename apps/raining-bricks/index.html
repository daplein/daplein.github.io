Download for Android

Android 13 or newer. Plays in portrait.

Chrome will ask "File might be harmful". It asks that for every app that isn't from the Play Store. Tap Download anyway.

It only asks once the whole 23 MB has downloaded, so keep this page open. If you tap Cancel, go back or close the page, Chrome throws the file away.

How to install

  1. Tap Download for Android above and wait for it to finish.
  2. When Chrome asks File might be harmful, tap Download anyway.
  3. Tap Open (or open RainingBricks.apk from Downloads).
  4. If Android says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.
  5. Tap Install, then Open.

Already have it? Install the new version over the old one: your settings and best score stay.

Had the earlier version of this game? It has a new name now, so it installs next to the old one: install this, then uninstall the old one.

What's new in 1.0.0

It's raining bricks! 🧱 The block game has a name and a look of its own.

  • Bricks, not blocks: every piece is a little brick wall, each with its own clay colour and bond.
  • A wider board (11 × 22) and a landing guide that marks where the piece will rest.
  • Clear four lines at once for a HALLELUJAH! Spins into a slot are now twists.
  • New music: *Brick Rain*, written for the game.
  • Same controls, hold, cheats, leaderboard, Share and update check.
