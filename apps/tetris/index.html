Download for Android

Android 13 or newer. Plays in portrait.

Chrome will ask "File might be harmful". It asks that for every app that isn't from the Play Store. Tap Download anyway.

It only asks once the whole 23 MB has downloaded, so keep this page open. If you tap Cancel, go back or close the page, Chrome throws the file away.

How to install

  1. Tap Download for Android above and wait for it to finish.
  2. When Chrome asks File might be harmful, tap Download anyway.
  3. Tap Open (or open Tetris.apk from Downloads).
  4. If Android says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.
  5. Tap Install, then Open.

Already have it? Install the new version over the old one: your settings and best score stay.

What's new in 0.3.0

New: an online Leaderboard shared with friends. Tap Leaderboard on the start screen or after a game.

  • Every finished game is posted automatically. The first time, you pick a name.
  • Two boards: Legit, and Anything goes for games where you used a cheat.
  • Each phone shows once per board, with its best game. Your own row is highlighted.
