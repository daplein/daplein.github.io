Download for Android

For Android phones and tablets. Plays in landscape.

Chrome will ask "File might be harmful". It asks that for every app that isn't from the Play Store. Tap Download anyway.

It only asks once the whole 53 MB has downloaded, so keep this page open. If you tap Cancel, go back or close the page, Chrome throws the file away.

How to install

  1. Tap Download for Android above and wait for it to finish.
  2. When Chrome asks File might be harmful, tap Download anyway.
  3. Tap Open (or open TinyRacers.apk from Downloads).
  4. If Android says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.
  5. Tap Install, then Open.

Already have it? Install the new version over the old one: your settings and best laps stay.

Had Tiny Racers 0.3.0 or older? Uninstall it once first. The game moved to a new signing key in 0.4.0, so Android won't install the new version over the old one. From now on, updates install over each other.

What's new in 0.4.0

Share Tiny Racers with a friend: tap Share on the start menu and let them scan the code with their phone's camera.
